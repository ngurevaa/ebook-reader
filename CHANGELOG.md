# Changelog

## [1.0.0] - 2026-02-16

### Добавлено

- Авторизация пользователей
- Загрузка книг в форматах TXT, EPUB и PDF
- Хранение книг в Supabase Storage
- Хранение метаданных в Firebase Firestore
- Локальное хранение книг
- Фоновая загрузка через WorkManager
- Поиск и управление списком книг
- Экран чтения
- Настройки чтения
- Профиль пользователя
