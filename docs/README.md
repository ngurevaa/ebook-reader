# EBook Reader

Android-приложение для загрузки, хранения и чтения электронных книг.

Приложение позволяет авторизоваться, загружать книги в форматах TXT, EPUB и PDF, хранить их локально и в облачном хранилище, искать книги, читать их с настройкой внешнего вида и сохранять прогресс чтения.

## Возможности

### Авторизация

* регистрация и вход по email и паролю;
* авторизация с использованием Firebase Authentication;
* валидация email и пароля во время ввода;
* обработка ошибок авторизации;
* автоматический вход авторизованного пользователя.

### Работа с книгами

* загрузка книг в форматах `.txt`, `.epub` и `.pdf`;
* сохранение метаданных книги;
* хранение файлов книг в Supabase Storage;
* локальное хранение загруженных книг;
* синхронизация локального и облачного состояния;
* поиск по названию и автору;
* скачивание книг из облачного хранилища;
* удаление локальных книг;
* отображение количества книг с учётом правил множественного числа русского и английского языков.

### Чтение

* поддержка TXT, EPUB и PDF;
* отображение содержимого книги;
* настройка размера шрифта;
* светлая и тёмная темы чтения;
* сохранение прогресса чтения;
* отображение процента прочитанного.

### Профиль

* просмотр данных пользователя;
* изменение имени и email;
* загрузка изображения профиля;
* сохранение изображения в Supabase Storage;
* выход из аккаунта.

### Локализация

Приложение поддерживает русский и английский языки.

Локализованные строки хранятся в ресурсах соответствующих feature-модулей:

* `values/strings.xml` — английский язык по умолчанию;
* `values-ru/strings.xml` — русский язык.

Переключение языка выполняется непосредственно в приложении.

Для строк, зависящих от количества объектов, используются Android `plurals`. Например:

* `1 книга`;
* `2 книги`;
* `5 книг`;
* `21 книга`.

Android самостоятельно выбирает нужную форму в соответствии с текущей локалью и правилами множественного числа языка.

## Архитектура

Проект использует модульную архитектуру на основе Clean Architecture и MVI.

Основные функциональные области выделены в отдельные feature-модули:

```text
feature/
├── auth/
├── booklist/
├── bookupload/
├── profile/
└── reader/
```

Каждый feature разделён на два Gradle-модуля:

```text
feature:<name>/
├── api/
└── impl/
```

`api` содержит публичные контракты функциональности:

* интерфейсы UseCase;
* интерфейсы Repository;
* domain-модели;
* navigation routes;
* другие компоненты, необходимые для взаимодействия с feature.

`impl` содержит внутреннюю реализацию:

* Compose UI;
* ViewModel;
* State и Event;
* реализации UseCase;
* реализации Repository;
* DataSource;
* Mapper;
* DI-модуль;
* фоновые компоненты, если они необходимы feature.

Подробнее архитектура проекта описана в [architecture.md](docs/architecture.md).

## Работа с данными

Приложение использует несколько источников данных, каждый из которых отвечает за свою область:

```text
Firebase Authentication
        │
        └── данные авторизации пользователя


Firebase Firestore
        │
        └── метаданные книг


Supabase Storage
        │
        ├── файлы книг
        └── изображения профиля


Room
        │
        └── локальные данные книг


SharedPreferences
        │
        └── прогресс чтения
```

### Firebase Authentication

Используется для регистрации, входа и получения текущего авторизованного пользователя.

### Firebase Firestore

Используется для хранения метаданных книг пользователя.

### Supabase Storage

Используется для хранения файлов книг и изображений профиля.

Для подключения Supabase используются `SUPABASE_URL` и `SUPABASE_KEY`, которые передаются через `BuildConfig`.

### Room

Room используется для локального хранения информации о книгах.

Основные компоненты находятся в `core:database`:

```text
AppDatabase
    │
    └── BookDao
            │
            └── BookEntity
```

Локальное хранение позволяет отображать ранее загруженные книги без необходимости каждый раз обращаться к удалённому хранилищу.

### SharedPreferences

Используется в reader feature для сохранения прогресса чтения отдельно для каждой книги.

## Работа с книгами

Загрузка книги выполняется в несколько этапов:

```text
Выбор файла
    ↓
Ввод метаданных
    ↓
BookUploadViewModel
    ↓
UploadBookUseCase
    ↓
BookRepository
    ├── Supabase Storage
    ├── Firestore
    └── Room
```

Фоновая загрузка выполняется с помощью `WorkManager`.

`BookUploadWorker` получает параметры книги, запускает соответствующий UseCase и отображает уведомления о процессе и результате операции.

## Чтение книг

Для разных форматов используются специализированные библиотеки:

* TXT — чтение текстового файла;
* EPUB — Epublib;
* PDF — PDFBox Android.

Чтение выполняется через локальный DataSource.

Для EPUB и PDF содержимое обрабатывается частями, что позволяет не загружать весь документ целиком в память.

## Управление состоянием

Для presentation-слоя используется MVI с Orbit MVI.

Общий поток данных:

```text
Пользователь
    ↓
UI Event
    ↓
ViewModel
    ↓
UseCase
    ↓
Repository
    ↓
DataSource
    ↓
результат операции
    ↓
ViewModel
    ↓
State
    ↓
Compose UI
```

ViewModel является связующим звеном между пользовательским интерфейсом и бизнес-логикой.

UI отображает состояние и передаёт пользовательские события во ViewModel.

## Настройка проекта

Для запуска приложения необходимо настроить внешние сервисы.

### 1. Firebase

1. Создать проект в Firebase Console.
2. Добавить Android-приложение с идентификатором:

```text
ru.gureva.ebookreader
```

3. Скачать `google-services.json`.
4. Поместить файл в каталог `app/`.
5. Включить Firebase Authentication с методом входа Email/Password.
6. Создать и настроить Firestore.

### 2. Supabase

1. Создать проект в Supabase.
2. Создать Storage bucket с именем `books`.
3. Настроить необходимые политики доступа.
4. Создать файл:

```text
core/network/secrets.properties
```

5. Добавить в него:

```text
SUPABASE_URL=...
SUPABASE_KEY=...
```

Файл с секретными данными не должен добавляться в систему контроля версий.

### 3. Сборка

После настройки Firebase и Supabase открыть проект в Android Studio и выполнить Gradle Sync.

После успешной синхронизации приложение можно запустить на Android-устройстве или эмуляторе.
